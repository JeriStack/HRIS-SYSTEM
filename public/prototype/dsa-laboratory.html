Data Structures & Algorithms Laboratory

Interactive visual simulations, complexity benchmarks, and academic defense demonstrations.

Academic Project Context: This interactive laboratory demonstrates how data structures and algorithms enhance HRIS operations. Frontend simulations provide immediate visual intuition during system defense. Full production algorithms are implemented in native PHP within the backend architecture.

⏳ First-In, First-Out (FIFO) Queue — Leave Review Queue

Applications evaluated in exact arrival order. Prevents queue starvation.

Time: O(1) Enqueue / Dequeue

📚 Last-In, First-Out (LIFO) Stack — Recent Activity & Rollback

Most recent user operations sit on TOP of the stack.

Time: O(1) Push / Pop

🔗 Singly Linked List — Dynamic Leave Transaction Chaining

Nodes linked via pointers (head ➔ next ➔ null) without contiguous memory constraints.

Time: O(1) Insert Front • O(n) Traversal

🔑 Hash Table — O(1) Employee Record Indexing

Hashing employee key (e.g. 'EMP004') directly to an in-memory bucket index.

Average: O(1) Lookup / Insertion
Click "Execute Direct O(1) Lookup" to inspect memory bucket and collision bucket resolution.

🌳 Binary Search Tree (BST) — Hierarchical Directory Traversal

Ordered binary tree supporting logarithmic O(log n) search and recursive traversal.

Search: O(log n) • Traversal: O(n)
